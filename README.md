## About Me

I'm a BTech student who builds things around real problems I run into — an attendance system that couldn't be spoofed, a mic that never calibrated right, a prediction model for football matches I actually trust. Most of what's below started that way rather than as a tutorial project.

I build ML pipelines, APIs, and practical tools I actually use. Outside of code, I'm into football tactics & data, chess, and worldbuilding. Right now I'm training a match-prediction model. My philosophy: ship it working, then make it clever.

## Featured Projects

**[LiveFoot](https://github.com/Tinil-K-Benny/LiveFoot)** — a live football match prediction system. An automated worker ingests match data, a Scikit-Learn gradient boosting model turns it into a probability, and a Flask API feeds a React frontend.
`Python` `scikit-learn` `Flask` `React`

**[EchoID](https://github.com/Tinil-K-Benny/EchoID)** — a speaker recognition system that learns continuously. Uses Resemblyzer for voice embeddings, keeps a memory of speaker profiles, and scores real-time comparisons with cosine similarity, with duplicate prevention built in.
`Python` `Resemblyzer` `ML`

**[YouHadToBeThere](https://github.com/Tinil-K-Benny/YouHadToBeThere---spoof-proof-attendance-using-face-recognition-and-geolocation)** — a spoof-proof attendance system combining face recognition with geolocation, built as a DBMS project.
`Python` `MongoDB` `FastAPI` `Streamlit`

**[Nova_v1_beta](https://github.com/Tinil-K-Benny/Nova_v1_beta)** — an AI personal assistant handling basic on-device tasks. Early beta, actively evolving.
`Python`

**[mic-energy-calibrator](https://github.com/Tinil-K-Benny/mic-energy-calibrator)** — a lightweight tool for RMS energy calibration on microphone input, built as a utility for cleaner speech/audio processing pipelines.
`Python`

**[MisFit](https://github.com/Tinil-K-Benny/MisFit)** — a stray dog attack prevention system.
`Java`

**[Community-Fridge](https://github.com/Tinil-K-Benny/Community-Fridge)** — a desktop app (Java Swing) to centralize and automate managing a community fridge.
`Java`

**[Os-Automation](https://github.com/Tinil-K-Benny/Os-Automation)** — voice-prompt automation for opening and closing apps and websites.
`Python`
